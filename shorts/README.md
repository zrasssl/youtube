# $1 за каждый метр — Shorts-версии

Источник: ветка `claude/dollar-per-meter-shorts`, `dollar-per-meter/video/{ru,en}.mp4` (96,7 с / 97,8 с).

| Файл | Длина | Громкость |
|---|---|---|
| `dollar-per-meter-ru-short.mp4` | 53,6 с | −14,3 LUFS, пик −0,9 dBFS |
| `dollar-per-meter-en-short.mp4` | 53,4 с | −14,8 LUFS, пик −0,8 dBFS |

1080×1920, 30 fps, H.264 + AAC 256k, `+faststart`. В кадре 0 — обложка из `covers/`.

Вырезано: расчёт «6 000 шагов в день», «Правила простые», скриншоты Макса, «ноги стёрты»,
«потом приходит в себя… по 10 км», «25 км в дождь…», «Неплохо», «в два с половиной раза больше»,
весь блок «70 лет — 115 млн».
Склейки стоят в паузах (по распознанным словам и детектору тишины); каждый кусок проверен
повторным распознаванием — фразы целые, повторов нет. Точные отрезки исходника: `*.cuts.json`.
