# Семинар: связи, регрессия, прогноз (Online Retail II)

| Файл | Что внутри |
|---|---|
| `output/Otchet_seminar.docx` | Отчёт (2–3 стр. + приложение с графиками): связи, модель, прогноз, проверка, «чего мы не знаем» |
| `output/Seminar_OnlineRetailII.xlsx` | Книга Excel: данные по 4 239 клиентам, корреляционная матрица (КОРРЕЛ), регрессия, ряд с формулами (скользящее среднее, индексы, НАКЛОН/ОТРЕЗОК, прогноз, MAPE, наивные прогнозы) |
| `output/*.png` | Диаграммы рассеяния, график остатков, ряд с трендом и прогнозом |
| `output/results.json` | Все числа, на которые ссылается отчёт |

Воспроизвести (нужен `online_retail_II.csv` из UCI, id 502):

```
python3 prep.py online_retail_II.csv clean.pkl   # очистка
python3 build.py clean.pkl output                # расчёты, графики, Excel
python3 report.py output                         # отчёт docx
```

Главные результаты: r(выручка 2010, выручка 2011) = 0,88 → 0,69 без 1% крупнейших;
регрессия R² = 0,41, остатки — воронка; модель «тренд × сезонность» MAPE 6,1% против
5,9% у «как год назад» (ничья) и 38,1% у «как в прошлом месяце».
